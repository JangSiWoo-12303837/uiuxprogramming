# 면접 준비 서비스

예상 질문을 고르고 답변을 작성해 보는 면접 준비 웹페이지입니다.
`index.html`을 브라우저에서 열면 실행됩니다.

## 사용자와 목표

- 사용자: 면접을 준비하는 취업 준비생
- 목표: 예상 질문에 대한 답변을 작성하고, 기록한 내용을 확인한다.

## 사용자의 흐름

1. '예상 질문' 탭에서 연습할 질문을 선택한다.
2. '답변 연습' 탭에서 답변을 입력한다. 비어 있으면 기록 버튼을 누를 수 없다.
3. '답변 기록하기' 버튼을 누르고 완료 안내를 확인한다.
4. '연습 기록' 탭에서 질문과 답변을 확인한다.
5. 필요하면 '답변 연습' 탭으로 돌아가 내용을 수정하고 다시 기록한다.

## 6주차 이벤트와 동적 UI

### 구현한 이벤트

| 이벤트 | 적용한 곳                          | 동작                                                      |
| ------ | ---------------------------------- | --------------------------------------------------------- |
| click  | 예상 질문, 답변 연습, 연습 기록 탭 | 선택한 탭의 색을 바꾸고 해당 내용만 보여준다.             |
| click  | 답변 기록하기 버튼                 | 작성한 질문과 답변을 연습 기록에 표시한다.                |
| input  | 답변 입력창                        | 글자 수를 보여주고, 내용이 있으면 기록 버튼을 활성화한다. |
| input  | 이메일 입력창                      | 이메일 형식을 확인하고 신청 버튼을 활성화한다.            |
| change | 질문 종류 선택창                   | 선택한 질문을 화면에 표시하고 답변 입력창을 비운다.       |
| submit | 이메일 신청 폼                     | 페이지 이동 없이 신청 완료 문구를 보여준다.               |

### 함께 바뀌는 화면

- 답변 입력: 글자 수와 안내 문구가 바뀌고 기록 버튼이 활성화된다. 공백만 입력하면 버튼은 비활성화된다.
- 답변 기록: 안내 문구가 초록색 배경의 완료 문구로 바뀌고, 버튼도 '기록 완료'로 바뀌면서 비활성화된다.
- 이메일 입력: 형식에 따라 안내 문구와 신청 버튼의 활성화 상태가 바뀐다.
- 이메일 신청: 완료 문구와 배경색이 바뀌고, 버튼은 '신청 완료'로 바뀌면서 비활성화된다.
- 탭 선택: 선택한 버튼은 보라색으로 표시하고 다른 탭의 내용은 숨긴다.

### 화면 크기별 테스트 결과

Chromium 브라우저에서 화면 너비를 바꾸며 확인했다.

| 화면 너비 | 화면 확인                                             | 기능 확인                                         | 결과 |
| --------- | ----------------------------------------------------- | ------------------------------------------------- | ---- |
| 1100px    | 가로 스크롤 없이 표시되고 이메일 폼이 가로로 배치됨   | 탭 전환, 질문 선택, 답변 입력과 기록, 이메일 신청 | 정상 |
| 768px     | 메뉴와 이메일 폼이 세로로 배치되고 탭 3개가 표시됨    | 탭 전환, 질문 선택, 답변 입력과 기록, 이메일 신청 | 정상 |
| 390px     | 입력창과 버튼이 화면 안에 들어오고 긴 답변도 줄바꿈됨 | 탭 전환, 질문 선택, 답변 입력과 기록, 이메일 신청 | 정상 |

추가로 빈 답변, 공백만 있는 답변, 500자 답변, 잘못된 이메일도 확인했다.
질문을 바꾸면 입력 중인 답변이 비워지고, 이미 기록한 답변은 유지된다.
기록 후 답변을 수정하거나 신청 후 이메일을 수정하면 버튼을 다시 사용할 수 있다.
세 가지 화면 너비에서 JavaScript 오류는 없었다.

### 참고

- 연습 기록은 가장 최근 답변 1개만 보여준다. 새로고침하면 사라진다.
- 이메일 신청은 화면 변화만 구현한 실습 기능으로 실제 저장이나 이메일 발송은 하지 않는다.
